## 内置插件与收起条槽位（2026-11-06）

- 用量环、会话环、中心图案都做成内置插件，在"插件扩展"里开关，不另设功能开关。（用户确认：插件形态）
- 用量环是同心双环：外环 5 小时、内环 7 天。（用户确认）插件叫「Agent 用量环」，Claude Code、Codex、GLM、Kimi 各一个开关，每个打开的 Agent 一个环，可以同时上岛，各有自己的颜色。（用户要求 2026-11-08）会话环是一个分段环，每段一种会话状态，中心可写总数。（用户确认）会话环另有像素格、状态条和信号格三种样式，在插件设置「样式」里选，默认仍是分段环。（用户要求 2026-11-08）
- 收起条有三个槽位，都空着时收起条与现在完全一样（Agent 推断，依据审阅报告）：
  - 中心槽位：只在没有消息预览、翻译、Agent 标题、待办和名称时显示，占摘要的位置，在状态灯与右侧元素之间的剩余空间居中；点它和点小岛一样。
  - 仪表槽位：放在最右侧元素（收起灰点或会话数）紧前面，和音乐、文件中转按钮同一行间距。（2026-11-09 起这是默认位置，用户可以在设置里调，见文末「统一排序」。）
  - 会话槽位：AI Agent 开启时代替蓝色会话数；AI Agent 关闭时不显示，保留收起灰点。
  - 插件声明槽位要占的宽度（`centerWidth`、`sideWidth`），折叠岛按它变宽（最宽 340px），不挤压摘要。
- `MiniRing` 是纯 SVG 小环：同心环或单个分段环，12 点钟方向起顺时针，圆头，默认 20px、线宽 2.5、环距 1.5，底轨白 16%；中心标签用 `--text-1`、600、等宽数字；数值变化 320ms 缓出，减少动效时不动画。值为 0 的环只画底轨，不画弧。（Agent 推断，依据审阅报告）
- 用量双环（内置插件 `focusd.claude-usage`，名称「Agent 用量环」）：每个打开的 Agent 一个环，24px（和会话环的分段环一样大；用户要求 2026-11-08），按 Claude Code、Codex、GLM、Kimi 排列，收起条每多一个环加宽 30px；全部关掉时不显示。外环 5 小时、内环 7 天，没有周限额的套餐（Kimi 新版会员）内环画本月；常态色各家不同：Claude Code `#E5A385`（橙）、Codex `#E6E6EB`（OpenAI 的黑白取近白）、GLM `#8B7BFF`（智谱标志的蓝紫）、Kimi `#3A8DFF`（Kimi 品牌蓝），≥70% 统一 `#E5C890`，≥90% 统一 `#E78284`（各家常态色为 Agent 推断：官方没有公开色值，按标志取色）；卡片第一行是 Agent 名和套餐（如「GLM · GLM Coding Pro」），用它的颜色；GLM 的 MCP 月度额度、Kimi 的本月额度列在 7 天之后。以下 Claude Code 的规则对各家通用：数据超过 15 分钟或没有数据时整体变灰（`#8E8E93`），没有数据时只画底轨。数据与 Agent 页顶部的用量相同：Claude Code 经本机 magpie 网关时读 magpie 的用量，否则读 claude-hud 的用量快照（都不联网、不读凭据）；插件设置「直接向 Anthropic 查询」打开时（默认关），两者取较新的一份。直接查询失败但数据仍新鲜时环不变灰，卡片里加一行原因；卡片最后一行写更新时间和来源（claude-hud / Anthropic）。环是按钮，点击立即请求刷新并重读（原生端 60 秒内只放行一次）。（用户确认：配色与过期、直接查询可选且默认关、不直连；点击行为为 Agent 推断）
- 会话环（内置插件 `focusd.session-ring`）：显示的就是 Agent 页列出的会话（含 Codex，跟着「隐藏已退出的会话」「只显示进行中」和 × 移除走，环自己不另设去留规则），列表里有几个、各是什么灯色，环里就是什么。（用户要求 2026-11-08：直接依赖主会话列表，不要和它对不上）AI Agent 开启时代替蓝色会话数，点击打开 Agent 页；AI Agent 关闭时不显示。颜色就是 Agent 页的灯色：等你确认（等审批或等回答，或失败且没看过）`#FF453A`、等你回复（回合结束、最后的回复在问你：回复状态标记 ↩，没有标记时看最后一段是否问句）`#FFD60A`、运行 `#34C759`、可能已停（运行中但很久没动静）半透明绿、完成（含看过的等你确认 / 回复）`#8E8E93`，按这个顺序排。四种样式，分段环和状态条的数字可以用插件的「显示会话数」开关关掉（默认开，关掉后只看颜色比例，环的大小不变）（用户要求 2026-11-08）：
  - 像素格：每个会话一格，4 个以内 2×2 格（8px），否则 3×3 格（6px），格距 2px、圆角 2px，没用到的格子画成白 10% 暗点，超过 9 个时最后一格画成加号、亮最急的 8 个；亮格带同色 5px 光晕，等你确认 1.4 秒一闪，运行 2.8 秒呼吸，收起条不在屏幕上或减少动效时不动。
  - 分段环（默认）：24px，中心写总数（一位数 12px，两位数 10px），从 12 点起顺时针。
  - 状态条：总数（11px）加一条 34×6px 胶囊，每种状态一段，长短按会话数分，段间 1px 断开，最短 3px。
  - 信号格：从左到右灰（完成）、绿（运行，可能已停的画成半透明绿叠在上面）、黄（等你回复）、红（等你确认）各一根 6px 宽的柱子，柱距 3px；没有会话的颜色不画柱子。每根柱子 5 个槽位，每个会话从下往上亮一格，没亮的画成白 10% 暗格（同像素格的空格），所以柱子一样高、在条里居中，亮了几格就是几个会话。横条粗细固定、所有柱子一样：5 个槽位时 3px（共 19px），任一根超过 5 个时每根都加到 6–7 个槽位、2px（共 17–20px），条距 1px；一根最多亮 7 格，再多的只在悬停卡片里计数。亮格光晕 2px（条距只有 1px，像素格的 5px 会把上面的暗格染色）。（用户要求 2026-11-08：柱子、颜色顺序、没有会话不出柱子；粗细固定而非填满高度、暗格槽位为 Agent 建议：填满后柱高不再表示数量，只画亮格时 1 个会话只剩一根 3px 短线，像出错）横条的圆角跟外观 → 圆角：岛屿圆角按收起条 38px 高等比缩到横条高度（最多半个条高，即胶囊），圆角样式（方圆 / 圆角）用同一个 `corner-shape`。（用户要求）
  （样式细节为 Agent 推断，截图检查过 1/3/6/12 个会话，信号格另看过岛屿圆角 16 / 40 和两种圆角样式）没有要显示的会话时整个环不显示，退回蓝色数字。悬停卡片列出各状态计数和前三个等你处理的会话"状态：标题 · 项目"，标题超过 40 字截断。（配色与优先级为用户确认；数据来源改为岛屿自己的会话列表为维护者决定）
  - 打开设置 → AI Agent → 连接 →「回复状态标记」（B9，推荐打开）后，已完成的会话按回复末尾的标记分：`↩` 等你回复为黄（看过也保持黄），`⋯` 等它自己的后台任务算运行（绿），`✓` 做完为灰；没有标记的会话沿用“没看过算等你回复”。Agent 页里等你回复的会话在状态行写「等你回复」。提醒和音效同样细分：等你回复按「等你确认 / 回答」弹出（受那个开关控制）并用「提问」音效，等后台任务不弹不响，后台任务结束、Claude Code 被唤醒接着做时也算同一轮，不弹「开始」、不响「收到」，卡片上的提问和计时仍是你那一条（issue #15）；做完照旧是完成。标记符号自定，不沿用 claude-sessions 的符号与文字。（用户确认做成可选、默认关；符号与文案为 Agent 推断，待用户审阅）
- 悬停详情卡片 `IslandHoverCard`（`src/components/`，用量环、会话环、Agent 页顶部用量行共用；用量行的卡片出现在这一行正下方，只写直接查询失败的原因和「更新时间 · 来源」，和用量环卡片的最后几行一致）：不用原生 `title`。光标停在环上 200ms 后，在胶囊正下方居中出现；会被鼠标指针挡住时整张移到指针左边（左边放不下就移到右边），鼠标在触发区里移动时跟着避让，键盘聚焦（`:focus-visible`）时立即出现；移开、按下、失焦或原生端报告光标离开岛时消失。底色用岛的 `--island-background-color`，1px 白 8% 描边、圆角 12、阴影；文字 12px，数据行 `--text-1`，次要行 `--text-3`，行首可带 6px 色点（环的颜色）。卡片画在 `.stage` 里、岛外面，不接收鼠标，不在原生点击区域内，因此不挡穿透、不抢焦点；环是按钮，按现有规则停在上面不会悬停展开。进场 140ms 淡入下移 4px，减少动效时不动画。（用户确认：卡片形式与位置；样式细节为 Agent 推断）

## 新消息横幅（C10，issue #13，2026-11-09）

- 设置 → 消息 →「新消息提示」选「一行预览 / 横幅」，默认一行预览，老用户不变。（用户确认）
- 横幅时 QQ、邮箱和插件通知（`island.notify`）在收起的岛正下方弹一张卡片，收起条保持原样，不再同时出一行预览；微信读不到内容，仍是收起条上的一行。（用户确认：收起条不重复、插件也走横幅）
- 卡片：宽 320px，岛下方 8px 居中；底色用岛的 `--island-background-color`，1px 白 8% 描边、圆角 16、阴影。左侧 20px 来源图标；第一行发送人 / 群名 / 插件标题（13px、600，单行省略）和右侧到达时间（11px `--text-3`，24 小时制）；下面摘要（12px `--text-2`，最多两行）；同组有多条时再写「另有 N 条」。右上角 22px 关闭按钮。插件通知的按钮排在卡片底部，与文字左对齐。进场 220ms 淡入下落，减少动效时不动画。（Agent 推断）
- 停留 5 秒（插件用它自己的 `durationMs`）；卡片显示期间新到的消息并进同一张，显示最新一条并重新计时。鼠标停在卡片上时不收回，离开后重新计满。点击卡片和点一行预览一样（QQ 打开 QQ，邮件打开岛内阅读页，插件通知关闭），点插件按钮运行动作，点关闭只收回。展开、贴边收起、托盘隐藏、全屏免打扰时不弹，已弹的立即收回；贴边时开着「有新消息时露出」的，岛滑出后再弹。（规则沿用一行预览，issue 中的要求）
- 卡片在原生点击区域内（`island/banner_hit.rs`，前端交出卡片的矩形），所以能点；但停在卡片上不算停在岛上，不会触发悬停展开。（Agent 推断）

## 折叠态中心图案

- 摘要为空时折叠岛中间显示一个图案：内置四款 SVG 动画（跟随光标的眼睛、小鸟、呼吸光点、小猫），或一只 Codex Pets 宠物（petdex 格式，读 `~/.codex/pets` 与应用数据目录 `pets/`，同名时应用数据目录优先）。不做任意单张图片导入。（用户确认）
- 图案 22px 高、最宽约 44px，白 / 浅灰为主，喙、脚、耳内少量暖色；只动 transform / opacity，循环 5–9 秒，岛展开、贴边收起和"减弱动态"时停住。眼睛跟随窗口外的光标靠原生端约 28Hz 的 `island-cursor-moved` 事件，只在眼睛显示时开启；4 秒没有光标变化就自己缓慢环视。（Agent 推断）
- 宠物按状态播放 petdex 的行：空闲 idle、运行 running、等待确认 waiting、失败 failed、完成 waving；帧数和循环时长照 petdex 渲染器的状态表。图集总是大幅缩小显示，用平滑采样（`image-rendering: auto`），像素风也不用 `pixelated`。v2 的 8×11 图集按前 9 行使用。（Agent 推断）
- 中心图案是内置插件"中心图案"（`focusd.center-pattern`，默认关闭），设置里选图案（眼睛 / 小鸟 / 光点 / 小猫 / 宠物）和宠物；宠物从本机找到的列表里选，不手填 id。（用户确认：插件形态）图案默认「宠物」、宠物默认小八（`xiaoba`）；本机没有这个宠物包时显示眼睛。（用户要求 2026-11-08）
- 选的是宠物时，折叠条显示 Agent 标题的那一刻，宠物（18px 高，约 16.6px 宽，与 16px 图标占位一致）跟随状态替换标题前的 Agent 图标；没有标题时照旧在中心显示。内置 SVG 图案只在没有摘要时出现。（Agent 推断，待用户确认）
- 折叠岛 38px 高：内置图案保持 22px，宠物放大到 28px。中心显示时折叠岛加宽（SVG 图案 44px、宠物 30px），避免被状态文字和右侧按钮挤掉。岛展开、贴边收起、全屏免打扰、窗口被托盘隐藏时暂停。宠物图集和读取失败都缓存，中心槽反复显隐不重新读取。宠物状态跟本应用读到的 Agent 会话：有等待确认演 waiting，有运行演 running，失败或可能中断演 failed，刚完成挥手约 3 秒后回 idle；宠物不存在或读不到时显示眼睛。（Agent 推断）

## 收起条上的项目：统一排序（2026-11-09，issue #17）

- 收起条上常驻的每个图标都是一个项目，位置只在 外观 → 收起条上的项目 里调：摘要左右两侧各一组，每组可以放多个，可以上移 / 下移、换到另一侧、隐藏（状态灯也能隐藏）。插件自己不设位置选项。（issue #17 提议，用户确认：都做）
- 默认布局就是原来的样子：左侧只有状态灯；右侧依次是新邮件、更新提醒、插件状态、摄像头 / 麦克风、文件中转数量、音乐、用量环、会话数。老用户升级后看不出变化。（用户要求，见 issue）
- 一个插件可以有多个项目：用量环每个 Agent 一项，相邻的用量环仍共用原来较小的间距；插件的每个状态项一项，不再只显示优先级最高的一个。（issue #17 提议）
- 没有内容的项目（比如没有新邮件）不显示但保留位置；关掉的插件再打开时回到原来的位置；新出现的项目放在默认顺序里排在它前面的那一项后面。（Agent 推断）
- 收起按钮（AI Agent 关闭时最右边的灰点）、消息预览、音量和设备提醒、用量提醒、会议加入按钮、插件通知按钮不参与排序，规则不变。（issue #17 提议，收起按钮为 Agent 推断：保证收起条总有一个收起的地方）
- 宽度：每个显示的项目加它声明的宽度（目前只有用量环），和在哪一侧无关；隐藏的不算。（Agent 推断）
- 先做上移 / 下移，不做拖动。（Agent 推断，见 [collapsed-bar-items.md](../architecture/collapsed-bar-items.md)）
