# 待办

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 待办日期

- 待办输入框右侧有日期按钮（默认"Today"），点开系统日历选日期；选今天以后的日子时按钮变紫色，回车后待办进入"已安排"而不出现在今日列表，日期随之复位为今天。（上游 issue #30，用户确认）
- 有已安排待办时，标题旁出现带数量的日历按钮，进入"Upcoming"页按日期分组查看、删除；该页使用归档页的固定高度，不显示输入框。（Agent 推断）
- 到期待办（日期不晚于今天，包括应用关闭期间错过的）在列表代表今天时并入顶部；列表还停在以前某天时先等跨天流程归档旧列表，再并入，避免被归档到旧日期。（Agent 推断）

## 显示风格：纸张 / 岛屿（C16，2026-11-09）

- 设置 → 待办 →「显示风格」：纸张（默认，上游原样保留）/ 岛屿。两种风格共用同一份数据和同一套页面（今天、笔记、已安排、归档、回看某一天），只换画法。（用户要求：不喜欢白色纸张，上游要保留）
- 岛屿风格没有自己的底板，直接画在岛上，和 Agent 页一样；文字和浅色底层都用岛屿的墨色（`--island-ink-rgb`），所以浅色岛屿底色上是深字。「待办纸张颜色」只对纸张生效。（Agent 推断）
- 顶部：四个有名字的标签页「今天 N / 笔记 / 已安排 N / 归档」，代替纸张左侧三个看不出意思的彩色圆点和右上的切换按钮；当前页底色白 9%，今天页的数量在当前页时是强调色小圆标。「已安排」只在有安排的待办或正打开它时出现。右侧在今天页放保存按钮：平时是下载图标，保存中转圈，保存好变绿勾，没设保存位置或失败时变黄色感叹号，读屏说明各自的意思。（Agent 推断）
- 输入框：38px 高，墨色 6% 底、1px 墨色 10% 边、圆角跟内层面板；左边加号，右边日期按钮（今天 / 明天 / 几月几日，选以后的日子时变紫，提示文字写出那天）。（Agent 推断，规则沿用纸张）
- 每一行：不再是卡片，平时无底色，悬停或键盘聚焦时墨色 6% 底；18px 圆形勾选框，完成后绿色实心、标题变灰并划掉；标题 14px、500、19px 行高。开始、删除、拖动三个 26px 图标按钮只在悬停或聚焦时出现。正在做的那一行有浅蓝底和左侧 3px 强调色竖条，右边一直显示「■ 进行中」，悬停时变红色「结束」。一行加间距 46px、每多一行标题加 19px，和纸张一样，岛屿按行长高的算法不变。（Agent 推断）
- 空列表：图标加「今天还很轻 / 在上面输入一件事，回车添加」，不画虚线框。笔记页是一块墨色 6% 底的输入区。已安排沿用按日期分组的列表，换成行的画法，删除按钮悬停才出现。（Agent 推断）
- 归档：不再分卡片和时间线两种布局，只有一个列表，新的在上、按月分组；每天一行写日期和星期、第一件没做完的事、完成进度条和「2/3」。点进去是回看页：返回按钮写日期，右边「完成 2/3」，列表只读。（Agent 推断：一个列表一眼看到哪天做了多少，比卡片和时间线信息多）
- 插件右键菜单和拖动排序照旧（行带 `data-todo-id`，在 `.todo-list` 里）。
