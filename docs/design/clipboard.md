# 剪贴板

调研见 [clipboard-managers.md](../research/clipboard-managers.md)，任务 C22。

## 打开方式（2026-11-09）

- 快捷键默认打开**独立窗口**，在鼠标旁弹出（放不下时翻到鼠标另一侧，始终在屏幕工作区内），也可选屏幕中间偏上；设置里可改回「岛上页面」，和以前一样展开岛的剪贴板页。（用户确认：默认独立窗口）
- 窗口和岛同样的深色圆角面板，宽 380：搜索框、记录列表、底部一行按键说明。前 9 条左边有数字。↑↓ 选择（到头会绕回），Enter 或点一条粘贴，搜索框为空时按 1–9 直接粘贴那一条，Esc 或点窗口外关闭。每条右侧的星标收藏，选中或已收藏时显示。（Agent 推断，参照 Ditto、Maccy、EcoPaste）
- 选中后**自动粘贴**：先把它放回剪贴板，关窗口，把焦点还给弹出前的窗口，再发 Ctrl+V（不用 Shift+Insert，VS Code 会当成改写模式）。设置里可关掉，关掉后只复制。（Agent 推断）
- Win+V（「快捷键」页，默认关）：打开后 Win+V 打开岛屿的剪贴板，代替系统自带的剪贴板历史；用低级键盘钩子实现，不改注册表、不重启资源管理器，关掉就还给系统。和录制的快捷键可以同时用。（用户确认要能用 Win+V；方式按调研选钩子）

## 图片和终端（2026-11-09）

- 图片记录多两个按钮：「复制为文件」（位图、PNG 之外再放文件，聊天软件和资源管理器里粘贴成文件）、「复制图片路径」（带引号的路径文字）。（Agent 推断，参照 QuickClipboard）
- 自动粘贴到终端（Windows Terminal、WezTerm、Alacritty 等）时，图片改贴文件路径：Claude Code 会把粘贴进来的图片路径当成图片附上，而直接贴位图在它那里经常读不到。设置「粘贴图片到终端时贴文件路径」，默认开。VS Code 的内置终端分不出是终端还是编辑器，不算在内，用「复制图片路径」按钮。（用户确认：适配 Claude Code CLI 的图片）

## 记录（2026-11-09）

- 「不记录密码」默认开：剪贴板上带 `ExcludeClipboardContentFromMonitorProcessing`、`Clipboard Viewer Ignore`，或 `CanIncludeInClipboardHistory` 为 0 时不记录，和系统剪贴板历史的做法一样。（Agent 推断）
- 「自动清理」：不清理 / 1 / 7 / 30 / 90 天，按最后一次复制的时间，收藏的不删。默认不清理。（Agent 推断）

## 记录得更多（C24，2026-11-09）

- **密钥和令牌**：一整段没有空格、像 API Key、GitHub 令牌、AWS 密钥、JWT、私钥的文字，默认「打码」：照常记录和粘贴，列表里只显示前 4 个字符和圆点，搜索也不搜它的原文；可改成「不记录」或「照常」。（用户确认：都做；默认打码为 Agent 推断）
- **来源应用**：每条记录前面显示复制它的程序的图标（读不到时退回普通图标），名字跟在备注后面；「不记录这些程序复制的内容」填程序名（逗号分隔，自动补 .exe）。（Agent 推断）
- **文件**：在资源管理器里复制的文件进历史（默认开），显示第一个文件名和「+N」，粘贴回去仍是文件；贴到终端是带引号的路径。（Agent 推断）
- **格式**：从网页、Word 复制的文字连同 HTML 一起记下（默认开），粘贴时带格式；独立窗口里 Shift+Enter 或 Shift+点击粘贴成纯文本。（Agent 推断，参照 Maccy）
- **标签**：备注里写 `#词` 就是标签（最多 8 个，每个 16 字以内），显示成备注前的小标签；点一下只看这个标签，搜索框里写 `#词` 也一样。没有单独的标签管理界面。（Agent 推断）
- **常用片段**：「设置 → 剪贴板 → 常用片段」新建和修改；剪贴板窗口按 Tab 切到「片段」，Enter 粘贴。粘贴时填好 `{date}`、`{time}`、`{datetime}`、`{weekday}`（中文星期）、`{clipboard}`，`{{`、`}}` 写出花括号本身。片段不进历史。（Agent 推断，参照 Clipy、Ditto）
- **顺序粘贴**：剪贴板窗口里 Ctrl+点击或 Ctrl+空格挑几条，数字列显示顺序；Enter 先贴第一条，之后你每按一次 Ctrl+V 就贴下一条，贴完最后一条自动结束；Esc 取消挑选，再次打开剪贴板窗口也会结束顺序粘贴。用 Win+V 的那个键盘钩子看 Ctrl+V，不吞按键。（Agent 推断，参照 TieZ）
