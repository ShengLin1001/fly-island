C10 横幅之后的第三种「新消息提示」：岛自动展开到消息页，只列这次弹出期间到达的消息，到时间自己收起。仿照 Agent 弹出提醒（`useIslandAgentAlerts`）：鼠标停在岛上不收，在面板里点过就不再自动收起。

用户确认（2026-11-09）：
- 设置「新消息提示」变成三选一：一行预览 / 横幅 / 展开面板，默认一行预览。
- 微信也进面板（一行「微信有新消息」，点它打开微信）。
- 停留时间单独可设，默认 8 秒。
- 插件通知也进面板，动作按钮放在那一行上。
