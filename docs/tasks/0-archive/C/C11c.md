## 说明

「正在播放」的通知显示插件图标、写着 Now playing，在弹出面板里还套着「新消息」标题和一张卡片。用户在三种做法里选了扩展插件 API（2026-11-09）：`island.notify` 加可选的 `icon: "media"`（正在播放的音乐软件的 exe 图标，由宿主读取后以 `iconUrl` 发给页面）和 `layout: "inline"`（弹出面板里只有这一条时不显示标题行和卡片），能力 `notifyStyle`。

## 提交

- `feat(plugins): island.notify can show the playing app's icon and an inline layout`

## 备注

- 同时修了弹出面板里卡片没有撑满岛宽度的问题（`.message-arrivals` 的 `align-self: start` 让它按内容收缩）。
- 示例插件 `dev.focusd.now-playing` 1.2.0（发歌名 / 歌手，`icon: "media"`、`layout: "inline"`）没有随这次提交：版本号变了就要同时打包，等于对外发布到插件市场，等用户确认。
- 打包好的商店应用（app id 带 `!`，如 Spotify 商店版）读不到 exe 图标，退回插件图标。
