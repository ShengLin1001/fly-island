## 说明

GitHub issue #14：插件名去掉「示例」；设置里填多个仓库，每个仓库一组；显示 GitHub 的剩余请求次数；可选用 GitHub 账号登录（默认关闭）。

## 验收

- 仓库用逗号分隔，最多 20 个；每组标题 `owner/name - N open`，条目 id 是 `owner/name:123`；一个仓库出错（404、写法不对、次数用完）只影响那一组。
- 页面最上面一行显示匿名还是已登录、剩余次数和刷新间隔；仓库多时间隔自动拉长到每小时不超过 50 次。
- 设置「用 GitHub 账号登录」默认关闭；打开后用设备码登录，令牌存凭据管理器（可选权限 `secrets`，用到时询问），失效或过期时退回匿名；关掉开关或退出登录会删除令牌。
- 不读取本机 `gh` 的令牌。
- `tests/scripts/github-issues-plugin.test.mjs` 在模拟宿主和本机假 GitHub 上跑通多仓库、出错的仓库、登录（含 GitHub 回 slow_down）和退出、不填 Client ID 时用内置的 App 几种情况。
