## 说明

在 TixXin 账号下新建 GitHub App：打开 Enable Device Flow；权限只要 Repository permissions 的 Issues: Read-only 和 Metadata: Read-only；可以关掉 Expire user authorization tokens（插件也处理了过期和续期，但续期是否需要 client secret 没有实测）。把 Client ID 写进 plugins/examples/dev.focusd.github-issues/main.ps1 的 $script:BuiltInClientId，真机登录走一遍，再 pnpm plugins:index 打包、land，最后改 focusd-plugins 里的 package 地址。新版本多了可选权限 secrets，市场会开 review-needed 等维护者审核。

## 提交
