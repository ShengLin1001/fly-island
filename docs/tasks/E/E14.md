## 说明

市场里 6 个插件同在一个仓库，GitHub 仓库的 star 区分不了插件。打算在 TixXin/focusd-plugins 给每个插件开一个 Discussion，用 👍 reaction 计数；仓库里的定时 Action 把各插件的数字写进一个 JSON，岛屿读这个文件，不需要登录、也不受匿名 API 次数限制。卡片上的 star 打开对应 Discussion，在 GitHub 上点赞。

## 验收

- 卡片显示 star 数，排序可选「默认 / 按 star」
- 计数文件取不到时市场照常可用，只是不显示数字
- 插件开发文档写明新插件怎么接入计数
