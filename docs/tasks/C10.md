GitHub issue #13。新消息到达时，在收起的岛下方弹出一张通知卡片，代替（可选）现在收起条里的一行预览。

用户确认（2026-11-09）：
- 设置「新消息提示：横幅 / 只用一行预览」，默认一行预览，不改老用户体验。
- 横幅弹出时收起条保持正常显示，不同时出一行预览。
- 插件的 `island.notify` 也走横幅（带插件的动作按钮）。
- 微信拿不到内容，不弹横幅，保持一行「微信新消息」。

要点：来源图标、发送人 / 群名、1–2 行摘要、到达时间；约 5 秒自动收回，悬停暂停；点击行为和现在点预览一致，有关闭按钮；短时间连续到达合成一张「另有 N 条」；展开、贴边收起、托盘隐藏、游戏模式下不弹（沿用预览的规则）。卡片要能点，原生点击区域（`island/passthrough.rs`）需要并入卡片的矩形。只用现有数据来源，不读聊天记录数据库。
