## 说明

收起条上每个图标的位置写死，内置插件只能进几个固定槽位。按 issue #17：每个图标是一个上岛项目，在 外观 → 收起条 统一排序；C9b（插件放左端）并入这一项。先在 docs/architecture/ 写分步计划再动手。

## 验收

- 左右两区都能放多个项目，可上移 / 下移、左右切换、隐藏（状态灯也能隐藏）
- 一个插件可以提供多个项目，市场插件也能声明
- 各插件设置里不再有自己的位置选项
- 默认顺序等于现在的布局，老用户升级后看不出变化
- 收起条宽度按实际项目计算，左侧也算
- 临时提醒（消息预览、用量提醒、设备提醒、会议按钮）不参与排序
