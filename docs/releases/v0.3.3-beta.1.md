## 关于这个版本

这是 0.3.3 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **新消息提示方式（新）**：设置 → 消息 → 新消息提示 可以选三种方式：
  - **一行预览**：和以前一样，默认。
  - **横幅**：QQ、邮箱和插件的新消息在收起的岛下方弹出一张卡片，写来源、发送人、两行摘要和到达时间，同一来源多条时显示「还有 N 条」。5 秒后收回，鼠标停在上面时不收；插件消息的按钮也在卡片上。微信读不到内容，仍是一行提示。
  - **展开面板**：新消息到达时岛自己展开到消息页，只列这次到达的消息（含微信），之后到的也加进来。停留时间可选 3 / 5 / 8 / 15 / 30 秒（默认 8 秒），鼠标停在岛上时不收；在面板里点过就不再自动收起。你自己展开着岛、游戏模式或岛被隐藏时不弹。
- **修复**：
  - 点击插件页面（例如系统监控的排序按钮）不再让展开的岛收起；切到别的窗口时照常收起。
  - AI 会话等自己的后台任务跑完、继续工作时，不再被当成新一轮开始，不再重复提醒和播放「开始」音效。

插件市场同时更新了几个插件（不需要更新岛屿，在插件市场里更新即可）：GitHub Issues 插件可以同时看多个仓库、显示本小时剩余的调用次数，并可选用 GitHub 登录；系统监控插件的刷新和程序列表恢复正常；番茄钟的倒计时恢复走动。

## About this release

This is the first beta of 0.3.3. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **New message alerts (new)**: Settings → Messages → New messages offers three ways:
  - **One line**: as before, the default.
  - **Banner**: new QQ, mail and plugin messages drop a card below the collapsed island with the source, sender, two lines of text and arrival time, and "N more" for a group. It slides back after 5 seconds unless the pointer rests on it; plugin messages keep their buttons on the card. WeChat gives no message text, so it stays a single line.
  - **Open panel**: a new message opens the island on the Messages page with just what arrived (WeChat included), and later arrivals join it. It stays 3 / 5 / 8 / 15 / 30 seconds (default 8) and holds while the pointer rests on the island; once you click inside it no longer closes by itself. It does not open while you have the island open, in game mode or with the island hidden.
- **Fixes**:
  - Clicking a plugin page (such as the system monitor's sort buttons) no longer closes the expanded island; moving to another window still does.
  - When an AI session carries on after its own background task finishes, this is no longer taken for a new turn, so it no longer alerts again or plays the "start" sound.

Several plugins were updated in the plugin market at the same time (update them there; no island update needed): the GitHub Issues plugin follows several repositories, shows the calls left this hour and can optionally sign in with GitHub; the system monitor refreshes and lists programs again; the pomodoro countdown ticks again.
