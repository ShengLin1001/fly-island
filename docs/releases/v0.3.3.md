## 关于这个版本

0.3.3 正式版，包含 0.3.3 测试版的全部内容和之后的改动。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

- **收起条上的项目可以自己排（新）**：设置 → 外观 → 收起条上的项目，摘要左右两侧的图标（状态灯、新邮件、更新提醒、插件状态、摄像头 / 麦克风、文件中转、音乐、用量环、会话数）都可以调顺序、换到另一侧或隐藏，左侧也能放多个，状态灯也能隐藏。用量环每个 Agent 一项，插件的每个状态项各是一项（以前只显示优先级最高的一个）。不改设置时和以前一样。
- **新消息提示方式（新）**：设置 → 消息 → 新消息提示 可选三种：
  - **一行预览**：和以前一样，默认。
  - **横幅**：QQ、邮箱和插件的新消息在收起的岛下方弹出一张卡片，写来源、发送人、两行摘要和到达时间，5 秒后收回，鼠标停在上面时不收。微信读不到内容，仍是一行提示。
  - **展开面板**：新消息到达时岛自己展开到消息页，只列这次到达的消息（含微信），停留 3–30 秒（默认 8 秒），在面板里点过就不再自动收起。
- **Agent 用量环**：原来的「Claude 用量环」改为 Agent 用量环，Claude Code、Codex、GLM、Kimi 各一个开关，每个打开的 Agent 在收起条上一个环，各有自己的颜色，达到 70% / 90% 时变黄 / 变红。Codex 读本机会话记录；GLM 和 Kimi 用插件页保存的 API Key 直接查询官方接口，Key 存在 Windows 凭据管理器里。环改为 24px，和会话环一样大。
- **会话环**：和 Agent 页的会话列表完全一致，用同样的灯色。新增像素格、状态条、信号格三种样式（默认仍是分段环），可以关掉中间的会话数。
- **SSH 代理隧道（新内置插件，默认关闭）**：把这台电脑的代理借给 SSH 远程主机用，每台主机一个服务器端口。本地代理端口默认自动识别（Clash Verge、v2rayN、系统代理），端口变了会自动重连。
- **插件市场**：
  - 默认列出全部插件，已安装的不再收起来；卡片上可以收藏，分类里多了「收藏」，收藏只存在本机。
  - 卡片显示插件在 GitHub 上的点赞数，可以按点赞数排序，点 👍 打开对应的点赞帖去点赞。
- **邮箱**：标签、横幅和收起条上改用通用的信封图标，不再是 QQ 邮箱的标志（邮箱本来就支持 163、126 等任意 IMAP 邮箱）。
- **修复**：
  - 邮件阅读页里点正文的链接没有反应，现在会用默认浏览器打开。插件详情页里的链接同样修好了。
  - 点插件页面（例如系统监控的排序按钮）不再让展开的岛收起；切到别的窗口时照常收起。
  - AI 会话等自己的后台任务跑完、继续工作时，不再被当成新一轮开始，不再重复提醒和播放「开始」音效。
  - 调过岛屿大小（缩放不是 100%）时，展开、收起的动画里文字不再抖动。
- **其他**：中心图案的宠物默认是「小八」（只影响没选过的用户）。

插件市场同时更新了几个插件（在插件市场里更新即可）：GitHub Issues 插件可以同时看多个仓库、显示本小时剩余的调用次数，并可选用 GitHub 登录；系统监控插件的刷新和程序列表恢复正常；番茄钟的倒计时恢复走动。

## About this release

The 0.3.3 release, with everything from the 0.3.3 beta and the changes since. Install over your current version. Todos, notes, settings and connected mailboxes are kept. The installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

- **Arrange the collapsed bar (new)**: Settings → Appearance → Items on the collapsed bar lists the icons left and right of the summary (status light, new mail, update, plugin statuses, camera / microphone, file shelf, music, usage rings, session count). Reorder them, move them to the other side or hide them; the left side takes several, and the status light can be hidden too. Each agent's usage ring and each plugin status item is its own item (before, only the plugin status with the highest priority showed). Untouched, the bar looks as before.
- **New message alerts (new)**: Settings → Messages → New messages offers three ways:
  - **One line**: as before, the default.
  - **Banner**: new QQ, mail and plugin messages drop a card below the collapsed island with the source, sender, two lines of text and the time, and slide back after 5 seconds unless the pointer rests on it. WeChat gives no message text, so it stays a single line.
  - **Open panel**: a new message opens the island on the Messages page with just what arrived (WeChat included) for 3–30 seconds (default 8); once you click inside it stays open.
- **Agent usage rings**: the Claude usage ring becomes Agent usage rings, with a switch each for Claude Code, Codex, GLM and Kimi and one ring per agent on the collapsed bar, each in its own colour, turning yellow at 70% and red at 90%. Codex reads its local session logs; GLM and Kimi ask their official endpoints with an API key saved from the plugin page in Windows Credential Manager. The rings are 24px now, the session ring's size.
- **Session ring**: shows exactly the Agent page's list in its light colours. New pixel grid, state bar and signal bars styles (the segmented ring stays the default), and the count in the middle can be switched off.
- **SSH proxy tunnel (new built-in plugin, off by default)**: lends this computer's proxy to your SSH hosts, one server port per host. The local proxy port is found automatically (Clash Verge, v2rayN, the system proxy), and the tunnels reconnect when it moves.
- **Plugin market**:
  - Lists every plugin, installed ones included; star a card to keep it under the new Starred filter, on this computer only.
  - Cards show each plugin's likes on GitHub and can be sorted by them; the 👍 opens the plugin's post to like it there.
- **Mail**: tabs, banners and the collapsed-bar badge use a plain envelope instead of the QQ Mail logo (mail works with any IMAP mailbox, 163 and 126 included).
- **Fixes**:
  - Clicking a link in a mail did nothing; it opens in the default browser now. Links on plugin detail pages are fixed the same way.
  - Clicking a plugin page (such as the system monitor's sort buttons) no longer closes the expanded island; moving to another window still does.
  - An AI session carrying on after its own background task is no longer taken for a new turn, so it no longer alerts again or plays the "start" sound.
  - With an island size other than 100%, text no longer wobbles while the island opens and closes.
- **Other**: the centre pattern's pet defaults to "xiaoba" (only if you never picked one).

Several plugins were updated in the plugin market at the same time (update them there): GitHub Issues follows several repositories, shows the calls left this hour and can optionally sign in with GitHub; the system monitor refreshes and lists programs again; the pomodoro countdown ticks again.
