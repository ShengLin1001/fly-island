## 关于这个版本

这是 0.3.4 的第二个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **日历月视图（新）**：日历页变宽，日程旁边多了一个月历，从周一排起，可以翻月、按方向键选日子、一键回到今天，点某一天就只列那天的日程。中文界面下每天写农历、节日和节气，订阅了节假日的显示「休 / 班」；今天和明天的标题带日期和星期。
- **插件页面更宽、不套卡片**：插件可以让自己的页面直接画在岛上，并在打开时让岛变宽。GitHub Issue、开发任务看板这类列表页也改成和 Agent 页一样：没有卡片，行不加底色，鼠标停上去才亮。
- **歌词**：
  - 歌词优先时，没找到歌词的歌在收起的岛上显示「歌名 - 歌手」，不再整首歌都被 Agent 占着。
  - 网易云这类不报播放进度的播放器，换歌、暂停和继续改为听系统的媒体事件来计时，歌词对得更准；单曲循环时最后一句不会一直停在岛上。
- **审批和提问卡片**的按钮上写出快捷键。
- **音乐波形开关（新）**：设置 → 音乐 → 岛屿 里可以关掉收起的岛上跳动的音乐竖条，和 外观 → 收起条 里「音乐」的开关是同一个。

插件市场同时更新了（在插件市场里更新即可）：
- **系统监控 1.2.0**：页面改成左右两栏、不再滚动，在新版岛屿上不套卡片、岛自动变宽。任何显卡（不只 NVIDIA）都显示 GPU 占用，下面一排 3D、复制、视频解码、视频编码的引擎条；程序列表带程序图标，打开约 1 秒就出来，右上角能打开任务管理器；浅色岛屿底色上也看得清。
- **正在播放 1.3.0**：弹出的提示里带上一首、播放 / 暂停、下一首按钮。

插件作者：网页页面新增 `width` 和 `frame: "none"`，无卡片的页面主题颜色跟着岛屿底色；`island.notify` 新增 `controls: "media"`（能力 `notifyControls`）。见插件文档。

## About this release

This is the second beta of 0.3.4. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Calendar month view (new)**: the calendar page is wider and shows a month beside the day list, starting on Monday, with month turning, arrow keys, a back-to-today button, and a click on a day to list only that day. In Chinese each day shows its lunar date, festival or solar term, and a subscribed holiday calendar adds its 休 / 班 marks; today's and tomorrow's titles carry the date and weekday.
- **Wider plugin pages without a card**: a plugin can draw its page straight on the island and widen the island while it is open. List pages such as GitHub issues and the dev task board now look like the Agent page: no card, no box around rows, and only the hovered row lit.
- **Lyrics**:
  - With lyrics first, a song without lyrics shows "title - artist" on the collapsed island, so a running agent no longer holds it for the whole song.
  - For players that report no position, such as NetEase, the island now times track changes, pauses and resumes from the system's media events, so lyrics keep better time; with repeat-one the last line no longer stays on the island.
- **Approval and question cards** show their shortcut keys on the buttons.
- **Music wave switch (new)**: Settings → Music → Island can hide the moving music bars on the collapsed island; it is the same switch as Music under Appearance → Collapsed bar.

Plugins in the market were updated too (update them there):
- **System monitor 1.2.0**: two columns with no scrolling; on new islands without a card, the island widening for it. GPU load for any GPU, not only NVIDIA, with bars for 3D, copy, video decode and encode; program icons, a program list that shows within about a second, and a button that opens Task Manager; readable on a light island.
- **Now playing 1.3.0**: its popup carries previous, play / pause and next buttons.

For plugin authors: webview pages take `width` and `frame: "none"`, and a page without the card gets theme colors that follow the island; `island.notify` takes `controls: "media"` (capability `notifyControls`). See the plugin docs.
