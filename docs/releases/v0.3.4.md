## 关于这个版本

0.3.4 正式版，包含 v0.3.3 以来的全部改动（三个测试版的内容，以及之后的剪贴板和手机推送更新）。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

**岛上**
- **歌词上岛（新）**：设置 → 音乐 → 歌词 里打开「在收起的岛上显示当前歌词」，播放时收起的岛显示正在唱的那一句；没找到歌词的歌显示「歌名 - 歌手」。同一处可以选 AI Agent 运行时谁优先，默认歌词优先：Agent 会话开始、完成或出错时临时显示 4 秒，等你审批或回答时一直显示到你处理。
- **岛屿标志做状态灯（新，默认）**：收起的岛左侧的 Agent 状态灯换成岛屿标志，跟着 Agent 变化：运行时三个点、等你时黄灯闪、出错变红、完成打勾。设置 → AI Agent → 岛上 →「状态灯」可以改回圆点。
- **Agent 标题默认只在变化时显示**：会话开始、完成或出错时显示 4 秒，等你审批或回答时一直显示，其余时间显示待办。设置 → AI Agent → 岛上 →「什么时候显示」选「运行时」就是原来的样子。
- **顶部按钮换成图标**：展开岛顶部的页面圆点换成待办、音乐、日历、剪贴板、文件中转的图标，当前页带上该页的颜色；最左边打开 Agent 页的圆点换成机器人图标。打开「鼠标悬停切换页面」时，鼠标停在图标上就切过去，停留时间可调。
- **弹出提醒更紧凑**：新消息和 Agent 提醒自动弹出时不显示顶部栏，岛缩窄到只包住卡片。审批和提问卡片的按钮上写出快捷键。
- **音乐波形开关（新）**：设置 → 音乐 → 岛屿 里可以关掉收起的岛上跳动的音乐竖条。

**页面**
- **日历月视图（新）**：日历页变宽，日程旁边多了一个月历，可以翻月、按方向键选日子、点某一天只看那天。中文界面下写农历、节日和节气，订阅了节假日的显示「休 / 班」。
- **音乐页重做**：直接画在岛上，浅色岛屿上文字自动变深；长句折成两行；能读到进度的播放器显示进度条。网易云这类不报进度的播放器，改为听系统的媒体事件计时，点任意一句歌词就能对齐。已装 BetterNCM 时可以一键安装 InfLink-rs，按歌曲精确查歌词。
- **待办的「岛屿」样式（新）**：设置 → 待办 → 样式 可选「纸张」（默认，原来的笔记本）或「岛屿」（和岛上其他页面一样的深色列表，用文字标签切换今天、笔记、已安排和归档）。
- **邮箱图标**：每个邮箱显示自己服务商的图标（QQ 邮箱、网易、Gmail、Outlook）。

**剪贴板**
- **剪贴板窗口（新）**：快捷键打开一个独立的小窗口，搜索、方向键和回车选，1–9 直接粘贴，选中后回到原来的窗口自动粘贴；终端里图片粘成文件路径。可选用 Win+V 打开它，关掉后 Win+V 恢复成 Windows 自带的。
- **记得更多**：记录是哪个程序复制的（带图标），可以设置不记录某些程序；资源管理器里复制的文件进历史，粘贴回去仍是文件；文字保留格式，Shift+Enter 粘贴成纯文本。
- **密钥打码**：看起来像 API 密钥、token、私钥的内容默认打码显示，也可以选不记录；跳过密码管理器标记为不进历史的内容。
- **标签、片段和依次粘贴**：备注里写 `#词` 就是标签，点一下筛选；设置里存常用片段，窗口里按 Tab 切过去粘贴，支持 {date}、{time} 等占位；Ctrl+点击选几条，之后每按一次 Ctrl+V 粘贴下一条。
- 图片可以复制为文件或复制路径；可以自动清理 1–90 天前的记录，收藏的不清理。

**手机推送**
- **经 cc-connect 推送到 Telegram、Discord、飞书（新）**：内置插件「cc-connect 手机连接」可以下载 cc-connect、一步步建好机器人，并由岛让它一直运行。Agent 等你时，问题、计划或回复连同接管命令发到手机，回 /cd、/switch 就能接着答。
- **推送改为你离开时才发**：推送不再立刻发出，等你锁屏或离开电脑一段时间后才发；这期间你看过那个会话、或者它已经继续往下跑了，就不再发。

**插件**
- 插件页面可以不套卡片、直接画在岛上，并在打开时让岛变宽；GitHub Issue、开发任务看板这类列表页也改成和 Agent 页一样，没有卡片，行不加底色。
- 插件市场同时更新：**系统监控 1.2.0** 改成左右两栏、不再滚动，任何显卡都显示 GPU 占用和 3D、复制、视频解码、视频编码的引擎条，程序带图标，浅色岛屿上也看得清；**正在播放 1.3.0** 显示歌名和歌手，弹出提示里带上一首、播放 / 暂停、下一首按钮。
- 插件作者：网页页面新增 `width` 和 `frame: "none"`；`island.notify` 新增 `icon`、`layout` 和 `controls: "media"`。见插件文档。

**修复**
- 经典外观的收起岛不再有一条灰色渐变，点了岛上的按钮后边缘不会一直亮着。
- 岛展开、收起时 Agent 行和文字不再上下抖动一个像素。
- 打开悬停切换页面时，宽度不同的页面之间不再来回切换。
- 回复状态标记：给出下一步建议、让你回来告诉它时也标成 ↩，不再误标成已完成。

## About this release

The 0.3.4 release, with everything since v0.3.3: the three betas, plus the clipboard and phone push updates after them. Install over your current version. Todos, notes, settings and connected mailboxes are kept. The installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

**On the island**
- **Lyrics on the island (new)**: turn on "Show the current line on the collapsed island" under Settings → Music → Lyrics, and the collapsed island shows the line being sung; a song without lyrics shows "title - artist". The same place chooses what comes first while an AI agent runs, lyrics by default: an agent shows for 4 seconds when a session starts, finishes or fails, and stays while it waits for your approval or answer.
- **The island mark as the status light (new, default)**: the Agent status light on the collapsed island is now the island mark and acts out the agents: dots while running, a blinking yellow light while waiting, red on failure, a tick when done. Settings → AI Agent → On the island → Status light switches back to the dot.
- **Agent titles show on changes by default**: for 4 seconds when a session starts, finishes or fails, and while it waits for an approval or answer; your todo the rest of the time. Settings → AI Agent → On the island → When to show it → While running is the previous behaviour.
- **Icons in the header**: the page dots at the top of the expanded island are now icons for todos, music, calendar, clipboard and the shelf, the open one in its page's colour; the Agent dot is a Bot icon. With "Switch pages on hover" on, resting the pointer on an icon opens its page, after an adjustable time.
- **Tighter popups**: new messages and Agent alerts that open by themselves leave out the header, and the island narrows to the card. Approval and question cards show their shortcut keys.
- **Music wave switch (new)**: Settings → Music → Island can hide the moving music bars on the collapsed island.

**Pages**
- **Calendar month view (new)**: a wider calendar page with a month beside the day list, month turning, arrow keys, and a click on a day to see only that day. In Chinese, lunar dates, festivals and solar terms, and 休 / 班 from a holiday calendar.
- **Music page redone**: drawn straight on the island, with dark text on a light island; long lines wrap; players that report their position get a progress bar. For players that do not, such as NetEase, the island times songs from the system's media events, and clicking a line aligns it. With BetterNCM, InfLink-rs installs in one click for exact lyrics.
- **Island style for todos (new)**: Settings → Todos → Style offers Paper (default, the notebook) or Island (a dark list like the island's other pages, with named tabs for Today, Note, Upcoming and Archive).
- **Mailbox logos**: each mailbox shows its service's logo (QQ Mail, NetEase, Gmail, Outlook).

**Clipboard**
- **Clipboard window (new)**: the shortcut opens a small window of its own: search, arrows and Enter, 1–9 to paste, and the pick is pasted back in the window you were in; into a terminal an image goes as its file path. Win+V can open it instead of Windows' clipboard history, and is Windows' again when turned off.
- **It keeps more**: the program that copied each entry, with its icon, and programs whose copies are not recorded; files copied in Explorer, pasted back as files; formatting, with Shift+Enter for plain text.
- **Keys masked**: text that looks like an API key, token or private key is masked by default, or not recorded; what password managers mark as private is skipped.
- **Tags, snippets and sequential paste**: `#word` in a note is a tag that filters the list; saved snippets in Settings, pasted from the window's Snippets tab (Tab) with {date}, {time} and more filled in; Ctrl+click several entries and each Ctrl+V pastes the next.
- Images copy as a file or as their path; entries older than 1–90 days can be cleaned up, favourites stay.

**Phone push**
- **Through cc-connect to Telegram, Discord and Feishu (new)**: the built-in "cc-connect phone link" plugin downloads cc-connect, sets a bot up step by step, and keeps it running. When an agent waits for you, its question, plan or reply goes to your phone with /cd and /switch to carry on there.
- **Pushes wait until you are away**: a push is sent once the screen is locked or you have been away for a while, and dropped if you looked at the session or it moved on meanwhile.

**Plugins**
- Plugin pages can drop their card and widen the island while open; list pages such as GitHub issues and the dev task board now look like the Agent page.
- In the market: **System monitor 1.2.0** in two columns without scrolling, GPU load and 3D, copy, decode and encode bars for any GPU, program icons, readable on a light island; **Now playing 1.3.0** shows song and artist, with previous, play / pause and next in its popup.
- For plugin authors: webview pages take `width` and `frame: "none"`; `island.notify` takes `icon`, `layout` and `controls: "media"`. See the plugin docs.

**Fixes**
- The collapsed island in the classic look no longer shows a grey gradient, and its edges no longer stay lit after a click.
- Agent rows and text no longer step a pixel while the island opens and closes.
- With hover switching on, pages of different widths no longer switch back and forth.
- The reply status marker marks offers of a next step and requests to report back as ↩, not as done.
