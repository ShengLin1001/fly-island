## 关于这个版本

这是 0.3.5 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **微信提醒能看到是谁、说了什么（新，默认关）**：设置 → 消息 → 微信提醒 里打开「显示联系人和消息摘要」，微信闪烁时岛屿读它的聊天列表，按聊天弹出联系人和最后一条消息，和 QQ 一样；点预览直接打开那个聊天。这个开关会改运行中微信的一个辅助功能开关，让它像开着读屏软件一样公开界面，关掉开关、关掉微信提醒或退出岛屿时改回；这不是微信公开支持的做法，会多占一些资源。微信关进托盘时读不到，请用最小化代替关闭；同一处的「微信最小化时不占任务栏」（默认开）让最小化的微信看起来和关进托盘一样。
- **微信也弹横幅**：新消息提示选「横幅」时，微信也弹一张卡片，点它打开微信。
- **剪贴板导入导出（新）**：设置 → 剪贴板 → 导入导出，把历史（含图片）和片段存成一个 JSON 文件放到下载文件夹；导入时只添加还没有的。
- **图片里的文字（新）**：新复制的图片在后台用 Windows 自带的文字识别读出文字（只在本机），可以搜索，也可以复制识别出的文字。
- **出错提示跟随界面语言**：Bark、cc-connect、日历、翻译、用量环和邮箱的出错信息按岛屿的语言显示，不再中英混杂；外部服务返回的原话照旧原样显示。

## About this release

This is the first beta of 0.3.5. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **WeChat reminders say who and what (new, off by default)**: turn on "Show the contact and message" under Settings → Messages → WeChat reminders, and when WeChat flashes the island reads its chat list and shows the contact and last message per chat, like QQ; clicking a preview opens that chat. The switch flips an accessibility flag inside the running WeChat so it exposes its UI as it would to a screen reader, and flips it back when you switch it off, turn WeChat reminders off or quit the island; WeChat does not officially support this, and it costs some CPU and memory. Closed to the tray, WeChat cannot be read, so minimize it instead; the switch beside it (on by default) makes a minimized WeChat leave the taskbar, so it looks the same as closed.
- **WeChat gets a banner too**: with the banner notice, WeChat now drops a card as well, and clicking it opens WeChat.
- **Clipboard import and export (new)**: Settings → Clipboard → Import and export saves the history (images included) and snippets to one JSON file in Downloads; importing adds only what is not there yet.
- **Text in images (new)**: newly copied images are read in the background with Windows' own text recognition, on this computer only, so their text can be searched and copied.
- **Errors in your language**: Bark, cc-connect, calendar, translation, usage ring and mailbox errors follow the island's language; what an outside service said still shows as it is.
