## 关于这个版本

这是 0.3.4 的第三个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **剪贴板窗口（新）**：剪贴板快捷键现在打开一个独立的小窗口，出现在鼠标旁边或屏幕中间：上面是搜索框，下面是历史记录，可以用方向键和回车选，按 1–9 直接粘贴对应的一条，Esc 或点窗口外面关闭。选中后会回到你原来的窗口并自动粘贴；粘贴到终端里时，图片以文件路径粘贴，Claude Code 会把它当作图片附上。设置里也可以改回在岛上打开剪贴板页，或者只复制不粘贴。
- **用 Win+V 打开（可选）**：可以让 Win+V 打开岛屿的剪贴板窗口，代替 Windows 自带的剪贴板历史。不改注册表、不用重启资源管理器，关掉后 Win+V 恢复成 Windows 的。
- **剪贴板设置更完整**：窗口在哪里打开、自动粘贴、终端里图片粘成路径、自动清理多少天前的记录（1–90 天，收藏的不清理）、跳过密码管理器标记为不进历史的内容（默认开启）。
- **复制图片的两种方式**：历史里的图片多了两个按钮：复制为文件（聊天软件和资源管理器里能直接粘贴成文件），以及复制它的路径。
- **顶部的 Agent 按钮**：展开后最左边那个打开 Agent 页的小圆点换成了机器人图标，和旁边的页面按钮一样大，颜色照常跟着 Agent 状态变。
- **修复**：打开「鼠标悬停切换页面」时，不同宽度的页面之间切换会让按钮左右移动，停着不动的鼠标会被来回触发、在两个页面之间反复切换。现在只有鼠标真的移动时才切换。

## About this release

This is the third beta of 0.3.4. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Clipboard window (new)**: the clipboard shortcut now opens a small window of its own, by the pointer or in the middle of the screen: a search box over the history, arrows and Enter to pick, 1–9 to paste a row, Esc or a click outside to close. Picking one goes back to the window you were in and pastes it; into a terminal an image goes as its file path, which Claude Code attaches as an image. Settings can keep the island's clipboard page instead, or only copy.
- **Open it with Win+V (optional)**: Win+V can open the island's clipboard window instead of Windows' clipboard history. No registry change or Explorer restart; turned off, Win+V is Windows' again.
- **Fuller clipboard settings**: where the window opens, auto-paste, image paths in terminals, clean-up of entries older than 1–90 days (favourites stay), and skipping what password managers mark as not for clipboard history (on by default).
- **Two ways to copy an image**: images in the history get two more buttons: copy as a file (chat apps and Explorer paste the file) and copy its path.
- **The Agent button at the top**: the small dot at the left of the open island that opens the Agent page is now a robot icon, as big as the page buttons beside it, still coloured by the agents' state.
- **Fix**: with "Switch pages on hover" on, pages of different widths slid the buttons sideways, so a still pointer switched pages back and forth. Now only a moving pointer switches.
