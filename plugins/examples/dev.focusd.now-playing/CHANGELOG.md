# 更新记录

## 1.2.0

- 提示改成歌名和歌手，旁边是正在播放的音乐软件的图标，不再写「Now playing / 正在播放」。新消息「展开面板」里只有这一条时，没有「新消息」标题和卡片，整个岛就是这条提示。需要支持 `notifyStyle` 的岛屿；旧版岛屿照常显示歌名和歌手，用插件图标。

## 1.1.1

- 名字去掉「示例」。功能没有变化。

## 1.1.0

- 换歌时不再默认在岛上弹「正在播放」：岛屿的音乐页和收起条已经显示正在播放的歌，开了「展开面板」或「横幅」新消息提示时，它还会变成一张消息卡片。需要的话在插件设置里打开「换歌时提示」。命令「显示正在播放」照常可用。
- 设置关闭时不订阅播放变化，所以不会一装上就询问播放信息的权限。
- 换上修好的 PowerShell 读取：等消息的超时在 Windows PowerShell 5.1 上恢复生效。
