# 更新记录

## 1.1.0

- 名字去掉「示例」。
- 可以填多个仓库（逗号分隔，最多 20 个），每个仓库一组；一个仓库出错只影响那一组。
- 页面最上面显示匿名还是已登录，以及这个小时还剩多少次请求；仓库多时自动拉长刷新间隔，次数用完时显示重置时间。
- 可选用 GitHub 账号登录（默认关闭）：在浏览器里输入验证码授权，令牌存进 Windows 凭据管理器（用到时才询问「密钥」权限），登录后每小时 5000 次请求。
- 用 ETag 请求，issue 没有变化时不重新下载。
