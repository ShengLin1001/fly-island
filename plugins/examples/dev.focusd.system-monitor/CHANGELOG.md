# 更新记录

## 1.1.0

- 监控页重新排版：不再套卡片，直接画在岛上；岛在这一页变宽（760px），左边是 CPU、GPU、每个核心、内存、网速，右边是最占 CPU 或内存的 6 个程序，不再出现滚动条。需要 FocuSD Island 0.3.4 或更新，旧版岛屿照旧显示窄页面。
- 程序带上自己的图标（每个程序只读一次）；系统进程这类读不到图标的显示首字母。
- CPU、GPU、内存各有一个小圆环；显存、显卡功耗和电池放在一行，电脑上没有的就不显示。

## 1.0.3

- 新设置「后台记录曲线」（默认关）：监控页关着时也每秒读一次 CPU、GPU 和网速，打开页面时曲线带着最近五分钟，不再只有打开之后的数据。开着时插件一直运行（约 80 MB 的 PowerShell 进程）。
- 曲线从一分钟加长到五分钟（每秒一个点）。

## 1.0.2

- 修复：监控页只偶尔刷新，「程序」一栏一直是空的。插件等岛屿消息时的超时在 Windows PowerShell 5.1 上不生效，两次消息之间读数就停住了（issue #12）。现在每秒刷新一次，程序列表每 3 秒更新。

## 1.0.1

- 作者改为 ShengLin1001（插件的设计来自他的 PR #7）。功能没有变化。

## 1.0.0

- 第一个版本：监控页（CPU、每个核心、GPU、内存、网速、电池、最忙的程序），收起条上可选的 CPU、内存和温度。
